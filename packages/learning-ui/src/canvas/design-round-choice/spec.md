# Canvas spec: Daily, hourly or streaming: what matters most?

## Teaching claim
In a design round, the choice between a daily batch, an hourly micro-batch and streaming is not a matter of taste. It flips with how fresh the data must be, what it costs to run and what the team can maintain. Streaming wins only when speed is everything and cost and skills hardly matter.

## Why a canvas
The interviewer's question usually hides the weights. Flipping one weight and watching the winner change shows why the first move is to ask how fresh the data must be, and why a streaming answer to a morning report is a poor one.

## Model
- Options: Daily batch, Hourly micro-batch, Streaming.
- Criteria and scores (1 to 5, the course's judgment for a small team): Fresh data (daily 1, hourly 3, streaming 5), Low cost to run (5, 4, 2), Small team can run it (5, 4, 1).
- Weights: Nice to have 1, Important 2, Very important 3. Start: Fresh data 1, Low cost to run 2, Small team can run it 2.
- Formula: total(option) = sum of weight x score.
- Worked totals (daily, hourly, streaming): start 21, 19, 11; Fresh data 2 gives 22, 22, 16 (a tie of daily and hourly); Fresh data 3 gives 23, 25, 21; Fresh data 3 with cost 1 and team 1 gives 13, 17, 18.
- Assumptions: scores and weights are exact; one decision.
- Limitations: no late data, reruns, backfills or privacy; scores are judgments.
