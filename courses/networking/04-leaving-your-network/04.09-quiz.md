```quiz
type: mcq
question: "A computer is 192.168.20.5 with the mask 255.255.255.0 and the gateway 192.168.20.1. It sends one packet to 192.168.20.99 and another to 192.168.21.99. Which packets get the gateway's MAC as destination MAC?"
options:
  - "Only the packet to 192.168.20.99"
  - "Only the packet to 192.168.21.99"
  - "Both packets go to the gateway's MAC"
correct: 1
explanations:
  - "192.168.20.99 starts with the same three numbers as the computer's own address, so it is on the same network. That packet goes straight to its owner."
  - "Right. The mask keeps the first three numbers. 192.168.21.99 has a different third number, so it is far. Its frame goes to the gateway's MAC, and the IP address stays 192.168.21.99."
  - "Only a destination that fails the mask test goes to the gateway. 192.168.20.99 passes it, so its frame carries its own MAC."
```

```quiz
type: mcq
question: "A table has these rows: 192.168.5.0/24 connected; 10.0.0.0/8 via 192.168.5.2; 10.20.0.0/16 via 192.168.5.3 with metric 200; 10.20.0.0/16 via 192.168.5.4 with metric 100; default via 192.168.5.1. Where do a packet for 192.168.5.77 and a packet for 10.20.7.7 go?"
options:
  - "Direct to the host, then via 192.168.5.3"
  - "Via 192.168.5.1, then via 192.168.5.4"
  - "Direct to the host, then via 192.168.5.4"
correct: 2
explanations:
  - "The first part is right: 192.168.5.77 is in the connected row. But the two /16 rows tie on length, and the lower metric, 100, wins, so the next hop is 192.168.5.4."
  - "The default row is only for addresses that no other row holds. The connected row holds 192.168.5.77, so that packet goes direct."
  - "Right. The connected row holds the first address, so it goes straight to the host. For the second, the /16 rows beat the /8, and the lower metric picks 192.168.5.4."
```

```quiz
type: mcq
question: "A laptop at 10.0.0.15 sends a trace probe with TTL 1 toward 198.51.100.10. The first router on the way is 10.0.0.1 and the second is 192.0.2.1. Which address is the source of the reply that comes back?"
options:
  - "10.0.0.1"
  - "192.0.2.1"
  - "198.51.100.10"
correct: 0
explanations:
  - "Right. A probe with TTL 1 dies at the first router, and that router signs the Time Exceeded reply with its own address."
  - "The second router never sees this probe. It died one hop earlier, at the first router."
  - "The destination answers only when a probe reaches it. This probe stopped at the first router."
```

```quiz
type: mcq
question: "A computer has the address 192.168.7.100 and the mask 255.255.255.192. Which of these addresses is on the same network as it?"
options:
  - "192.168.7.60"
  - "192.168.7.120"
  - "192.168.7.130"
correct: 1
explanations:
  - "The mask 255.255.255.192 is a /26, so networks are 64 addresses long. 192.168.7.60 is in the block 0 to 63, but the computer is in the block 64 to 127."
  - "Right. 100 and 120 are both in the block 64 to 127, so applying the mask gives the network 192.168.7.64 for both."
  - "192.168.7.130 is in the block 128 to 191. The mask gives it a different network, 192.168.7.128."
```

```quiz

question: "A laptop at 192.168.1.23 wants to send a file to 192.168.1.40 on the same network. Its neighbour table is empty. What is the first frame it sends?"
options:
  - "The data frame, sent to the router's MAC"
  - "An ARP reply that gives the laptop's MAC"
  - "An ARP request to everyone on the link"
correct: 2
explanations:
  - "The neighbour is on the same network, so the router is not involved. The laptop first needs the neighbour's MAC."
  - "A reply answers a question, and nobody has asked. The laptop is the one who must ask."
  - "Right. The laptop has the IP address but not the MAC. It asks the whole link, at ff:ff:ff:ff:ff:ff, who has 192.168.1.40, and the owner answers."
```
