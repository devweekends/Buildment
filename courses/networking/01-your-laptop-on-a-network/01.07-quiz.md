```quiz
type: mcq
question: "On your computer, ipconfig shows IPv4 Address 192.168.0.14 and Default Gateway 192.168.0.1. Then curl.exe -4 ifconfig.me prints 203.0.113.60. These numbers are made up for the question. Which number does the website's server see as your visitor?"
options:
  - "192.168.0.1"
  - "203.0.113.60"
  - "192.168.0.14"
correct: 1
explanations:
  - "That is the gateway, the router's number inside your home. A website sees the router's number on the internet side, not this one."
  - "Right. The echo service reports the address that the website sees, and that is the number on the internet side of your router."
  - "That is your computer's own address. It works inside your home. The website never sees it."
```

```quiz
type: mcq
question: "One line of a capture reads: a2:bb:8c:3a:32:03 > ff:ff:ff:ff:ff:ff, ethertype ARP. Which kind of address is ff:ff:ff:ff:ff:ff, and who hears it?"
options:
  - "A MAC address, heard by every device on the link"
  - "An IP address, heard by every computer on the internet"
  - "A port, heard by every program on one computer"
correct: 0
explanations:
  - "Right. Six pairs of letters and digits is a MAC address. The all-f address is the broadcast one, so every device on the same link accepts the frame."
  - "An IP address has four numbers with dots. This address has six pairs with colons, and a frame sent to it never leaves the one link."
  - "A port is a single number from 0 to 65535 that names one program. This address has six pairs, so it is not a port."
```

```quiz
type: mcq
question: "One line of a ping capture reads: 192.168.1.10 > 192.168.1.20: ICMP echo request, id 584, seq 1, length 64. Where is the source port?"
options:
  - "It is 584, the number in the id field"
  - "It is 64, the number in the length field"
  - "There is none: ping uses no ports"
correct: 2
explanations:
  - "The id names this run of the ping command. It is a counter for ping, not the number of a program."
  - "The length is the size of the message in bytes. It says nothing about a program."
  - "Right. A ping is answered by the computer itself, not by a program, so the packet has no port field at all."
```

```quiz
type: mcq
question: "A Linux laptop sends a packet with TTL 64. It crosses two routers on the way. What TTL does tcpdump show at the far computer?"
options:
  - "ttl 64"
  - "ttl 63"
  - "ttl 62"
correct: 2
explanations:
  - "That is the TTL the laptop started with. Each router lowers it, so it cannot still be 64 after two routers."
  - "That is the TTL after one router. This packet crossed two."
  - "Right. Each router lowers the TTL by one, so 64 becomes 63 after the first router and 62 after the second."
```

```quiz
type: mcq
question: "A capture shows two lines. Line A: 192.168.1.10 > 192.168.1.20: ICMP echo request, id 45, seq 1. Line B: 192.168.1.20 > 192.168.1.10: ICMP echo reply, id 45, seq 1. Which computer ran the ping command?"
options:
  - "192.168.1.10, which sent the request"
  - "192.168.1.20, which sent the answer"
  - "Both, because both of them sent a packet"
correct: 0
explanations:
  - "Right. The request is the first packet and it comes from 192.168.1.10. The other computer only answers it."
  - "The reply is an answer. A computer sends a reply only after it has received a request, so it did not start the ping."
  - "Both sent a packet, but only one asked the question. The echo request shows which one started the ping."
```
