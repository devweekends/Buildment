```quiz
type: mcq
question: "A laptop has three sockets open: a video app on port 50010, a mail app on port 50012 and a music app on port 50014. Three replies arrive, addressed to ports 50014, 50010 and 50012, in that order. Which list gives the apps that receive them, in the same order?"
options:
  - "Video, mail, music"
  - "Music, video, mail"
  - "Mail, music, video"
correct: 1
explanations:
  - "That is the order in which the sockets were listed, not the order of the replies. Each reply goes by its own port."
  - "Right. Port 50014 is the music app, port 50010 is the video app, and port 50012 is the mail app."
  - "Check each port again. Port 50014 is the music app, not the mail app, so the first reply cannot go to mail."
```

```quiz
type: mcq
question: "Pick the best transport for each app. A: a sensor that sends the room temperature every 5 seconds. A lost reading is not worth resending, because the next one replaces it, and the sensor does not want a handshake for each small update. B: downloading a signed contract as a PDF. C: a live voice stream where a packet that arrives late is useless. Which pairing fits?"
options:
  - "A: TCP. B: UDP. C: TCP."
  - "A: TCP. B: TCP. C: UDP."
  - "A: UDP. B: TCP. C: UDP."
correct: 2
explanations:
  - "A contract with missing bytes is broken, so B needs TCP. A late voice packet is useless, so waiting for a resend over TCP does not help C."
  - "B and C are right here. For A, the next reading replaces a lost one, so waiting for a resend over TCP buys nothing, and UDP fits better."
  - "Right. The sensor reading is replaced in 5 seconds, so a gap is cheap: UDP. The contract needs every byte: TCP. Late voice is useless: UDP."
```

```quiz
type: mcq
question: "A router's table has three rows: 172.16.0.0/12 via 198.51.100.2, 172.16.5.0/24 via 198.51.100.6, and default via 198.51.100.10. A packet for 172.16.5.9 arrives. Which next hop does the router choose?"
options:
  - "198.51.100.6"
  - "198.51.100.2"
  - "198.51.100.10"
correct: 0
explanations:
  - "Right. 172.16.5.9 fits the /12 and the /24, and the router uses the most specific match: the /24, the longest prefix [S30]."
  - "The /12 row matches too, but it is the vaguer match. A row does not win because it is listed first."
  - "The default row matches every address, so it is the last resort. It is used only when no other row fits."
```

```quiz
type: mcq
question: "A laptop runs traceroute to the server 203.0.113.80. The path crosses two routers: the first at 192.168.1.1 and the second at 198.51.100.1. The probe with TTL 2 leaves the laptop. Which address is on the Time Exceeded message that comes back?"
options:
  - "Router 1, 192.168.1.1"
  - "Router 2, 198.51.100.1"
  - "The server, 203.0.113.80"
correct: 1
explanations:
  - "Router 1 lowers the TTL from 2 to 1 and passes the probe on. It answers only when the TTL reaches 0 there, which is the TTL 1 probe."
  - "Right. Router 1 lowers the TTL to 1. Router 2 lowers it to 0, discards the probe and sends Time Exceeded [S29, S30]."
  - "The server is reached only by a probe that survives both routers, which needs TTL 3. A TTL 2 probe never gets there."
```
