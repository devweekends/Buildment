```quiz
type: mcq
question: "Rana runs phone top-up kiosks in 4 towns. Her lake holds 365 days, about 2,000 rows a day. Her monthly report filters one town for 30 days. A power cut sometimes makes her nightly job run twice. From testing, she wants files of at least 1,000 rows. Which layout do the facts favour?"
options:
  - "One folder per day and town: 1,460 files, so the report opens only 30 files"
  - "One file for the year, with each night's rows added at the end of that file"
  - "One folder per day: 365 files of 2,000 rows, replaced one folder each night"
  - "One folder per town: 4 files, so the report opens just the one for its town"
correct: 2
explanations:
  - "This layout gives 365 x 4 = 1,460 files of about 500 rows each. That is below the 1,000 rows she wants, and the files are small enough to bring back the small-files problem."
  - "Adding rows at the end doubles a night's rows whenever the job runs twice, and a power cut sometimes makes it run twice. It is the append mistake from chapter 5.5."
  - "Right. 2,000 rows a day meets the 1,000-row minimum, and the nightly job replaces one folder, so a second run leaves the same result. The report opens 30 files of 2,000 rows."
  - "A town's file would hold about 182,500 rows, and the nightly job writes one day. Each night it would have to rewrite a whole town's file, which is far more work than one day's folder."
```

```quiz
type: mcq
question: "Osama's courier file has four row groups. The footer lists the price range of each, in shekels: group 1 is 3 to 22, group 2 is 5 to 41, group 3 is 24 to 39 and group 4 is 4 to 18. His query filters on price > 30. How many row groups must the engine read?"
options:
  - "Two, groups 2 and 3, because their largest prices are above 30"
  - "Four, because the prices in the file are not kept in sorted order"
  - "One, group 2, because it holds the highest price in the file, 41"
  - "Three, groups 1, 2 and 3, because each of them starts below 30"
correct: 0
explanations:
  - "Right. A group can hold a match only if its largest price is above 30. Group 2 (41) and group 3 (39) can. Group 1 (22) and group 4 (18) cannot, so the engine skips them."
  - "Sorting is not needed for this skip. Groups 1 and 4 have a largest price below 30, so the ranges alone rule them out."
  - "Group 3 also has a largest price above 30, 39, so it can hold a match. The highest value in the file does not decide which groups matter."
  - "The smallest value of a range does not matter for a filter of price > 30. Group 1 starts at 3 but ends at 22, so no row in it can be above 30."
```

```quiz
type: mcq
question: "Karim's clinic app has a patient table with 30 columns of similar width and 2 million rows. A clerk types an id and the app shows the whole record. Each night a report adds up 2 columns for all rows. Which statement do the facts support?"
options:
  - "A column layout suits both, because it always reads less data"
  - "A row layout suits both, because every query returns whole rows"
  - "Neither layout matters at 2 million rows, because engines are fast"
  - "A column layout suits the report; a row layout suits the lookup"
correct: 3
explanations:
  - "The lookup needs all 30 columns of one record, so a column layout must fetch 30 chunks to rebuild it. The saving is for queries that use a few columns."
  - "The report uses 2 of 30 columns. A row layout would read all 30 for every row, which is far more than the report needs."
  - "At 2 million rows the report reads 2 columns in one layout and 30 in the other, which is a clear difference. Speed does not remove it."
  - "Right. The report uses 2 of 30 columns of many rows, which a column layout skips. The lookup wants all the columns of one row, which a row layout keeps together."
```

```quiz
type: mcq
question: "Manar manages data for a youth centre. 8 staff run SQL on it. Each person needs a login, so trainers see attendance and only the manager sees phone numbers. The data is 300,000 rows, an overnight job changes some rows, and nobody has time to run extra services. Which design do the facts favour?"
options:
  - "A lake of Parquet files in a shared folder, because files are cheap and open"
  - "A warehouse, because it gives each person a login and updates rows safely"
  - "A lakehouse, because it keeps open files and adds safe updates to them"
  - "CSV files in a shared folder, because every staff member can open them"
correct: 1
explanations:
  - "A shared folder has only the permissions of the folder, so it cannot show phone numbers to the manager alone. The files are cheap, but logins for each person are a stated need."
  - "Right. A warehouse gives each person a login and permissions, changes rows safely, and 300,000 rows is small for one. It also asks nobody to run a separate layer."
  - "A lakehouse gives safe updates, but it adds a layer to run, and nobody has time for extra services. It also does not give a login for each person by itself."
  - "Anyone who can open the folder can read the phone numbers, so the manager's privacy need fails. CSV files also give no safe way to change rows overnight."
```

```quiz
type: mcq
question: "Sana's school uploads attendance sheets each evening, and teachers sometimes upload up to 2 days late. The lake has one folder for each upload date. The head teacher asks how many pupils were absent on 12 May. Sana filters upload_date = 12 May and gets 31. A teacher counts 36. What explains the gap and fixes it?"
options:
  - "The folder for 12 May is damaged, so rewrite it from the raw sheets"
  - "Partition skipping hides some rows, so switch it off for this query"
  - "Parquet drops some rows, so keep the attendance sheets as CSV files"
  - "Five sheets came in on 13 or 14 May, so filter by attendance date"
correct: 3
explanations:
  - "A damaged folder would not explain a gap of 5 that matches the late uploads. Rewriting it from the raw sheets would give the same 31."
  - "Skipping folders is correct here: she asked for the 12 May upload folder and got it. The question was about the attendance date, which a different column holds."
  - "Parquet keeps every row it is given. The missing five were never in the 12 May folder, because they were uploaded later."
  - "Right. A folder holds what arrived on its day, and late sheets sit in later folders. Filtering on the attendance date reads the later folders too and finds the missing five."
```
