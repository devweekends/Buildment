```quiz
type: mcq
id: books-model-q1
question: Two shops offer differently graded copies with the same ISBN. Which record does each shop own?
options:
  - Its Listing for one physical copy
  - The shared Edition for that ISBN
  - The Work grouping all the formats
  - The other shop's Listing after sale
correct: 0
explanations:
  - "A Listing contains the shop's own copy, grade, price and sale state."
  - "The Edition is shared by all offers for that ISBN."
  - "A Work groups related editions and is not shop-owned."
  - "One shop cannot take ownership of another shop's sold copy."
```

```quiz
type: mcq
id: books-model-q2
question: A student accepts Good or better. Good has rank 2. Which Listing filter applies?
options:
  - gradeRank equals 1 for the cheaper available copies
  - gradeRank is at least 2 for matching copies
  - gradeLabel contains the word good
  - priceMinor is at most 2 for all copies
correct: 1
explanations:
  - "Rank 1 represents Acceptable, which is below the stated floor."
  - "An ordered rank lets the query include Good and higher grades."
  - "Text matching on a label does not express an ordered threshold."
  - "A price ceiling is separate from a condition-grade floor."
```

```quiz
type: mcq
id: books-model-q3
question: A valid ISBN-13 starts with 979. What belongs in the Edition's isbn10 field?
options:
  - Its final ten ISBN-13 digits
  - Its first ten ISBN-13 digits
  - No ISBN-10 equivalent value
  - The 979 number with an X suffix
correct: 2
explanations:
  - "Truncation does not produce a valid equivalent ISBN-10."
  - "Dropping a suffix does not convert 979 to the old format."
  - "The 979 prefix has no backward-compatible ISBN-10 equivalent."
  - "X is only a possible final check symbol for a true ISBN-10."
```

```quiz

question: Shop B knows Shop A's Listing ID. What decides whether B can change its price?
options:
  - Whether both Listings share one Edition
  - Whether typed Work titles are equal
  - Whether a student saved the Listing
  - Whether B owns the Listing's Shop
correct: 3
explanations:
  - "A shared Edition permits comparison, not cross-shop editing."
  - "Title similarity is not an ownership relationship."
  - "A student's saved item cannot grant seller permission."
  - "The server checks the authenticated owner against Listing.shopId."
```
