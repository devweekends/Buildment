```quiz
type: mcq
question: Which file is safe to commit for teammates who need to configure the Ghurza server?
options:
  - server/.env with working credentials for each teammate
  - server/.env.example with variable names and placeholders
  - A full export of the production secret manager values
  - A log line that prints the full MongoDB connection string
correct: 1
explanations:
  - "A working credential file copies real secrets into every clone and into the repository history."
  - "The example file names every variable the server needs while keeping the values out of version control."
  - "Exporting the production secret store hands each teammate live credentials far beyond this project."
  - "A boot log that prints the URI writes the database password into logs that other people can read."
```

```quiz
type: mcq
question: Why should the server connect to MongoDB before it starts listening for HTTP requests?
options:
  - It stops routes accepting work the database cannot serve
  - It makes every MongoDB query run inside the browser tab
  - It removes the need for any error handling after startup
  - It automatically seeds the production data on every boot
correct: 0
explanations:
  - "A failed connection stops startup, so no route can accept work the database cannot complete."
  - "MongoDB queries always run in the server process, never inside the browser tab."
  - "A startup check does not replace error handling for queries that fail after the connection opens."
  - "Seeding is a separate script, and running it on every boot would rewrite production data."
```

```quiz
type: mcq
question: Which value must stay in server-side configuration rather than a Vite client environment variable?
options:
  - The public app name shown in the browser tab
  - The public API base URL used by the client
  - The MongoDB URI that carries credentials
  - A UI feature label defined in the config
correct: 2
explanations:
  - "The app name is public text and can travel to the browser without any risk."
  - "The API base URL reaches the browser by design because the client calls it."
  - "The URI carries the database user and password, so it stays on the server."
  - "A UI label is display text that holds no credential."
```
