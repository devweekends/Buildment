```quiz
type: mcq
id: handmade-model-q1
question: Two buyers begin checkout for one bowl. Which Piece change reserves it for one buyer?
options:
  - Set held with a checkout ID in a conditional write
  - Set stockQty to zero after reading the cart page, then save
  - Set the Artisan credit to the buyer's account ID
  - Set the request status to quoted before payment
correct: 0
explanations:
  - "A conditional available-to-held write makes one checkout claim the exact Piece."
  - "A prior cart read does not reserve a one-off object under concurrency."
  - "Artisan credit describes a maker and does not identify the buyer's hold."
  - "A quote belongs to future custom work, not this existing Piece."
```

```quiz

id: handmade-model-q2
question: Huda is credited on a Piece but has no seller account. Which link authorizes a price edit?
options:
  - Piece artisanId to Artisan display name
  - User ownerId to Workshop to Piece workshopId
  - Buyer ID to Cart to the Piece ID
  - CustomRequest ID to its inspired Piece ID
correct: 1
explanations:
  - "Credit is attribution and does not grant the seller's edit permission."
  - "The authenticated owner reaches the Piece through the Workshop relationship."
  - "A buyer's cart expresses interest and never grants listing control."
  - "Inspiration connects a request to a past Piece without changing ownership."
```
