```quiz
type: mcq
question: Why is bcrypt appropriate for storing Ghurza passwords?
options:
  - Its deliberate slowness and salting make guessing costly
  - It encrypts each password so the client can decrypt it
  - It stores the original plaintext password inside the hash
  - It removes the need for HTTPS on the login routes
correct: 0
explanations:
  - "Bcrypt salts every hash and is deliberately slow, so guessing a password costs real time."
  - "Hashing is one way on purpose; neither the client nor the server can decrypt it back."
  - "A bcrypt hash holds a salt and a derived digest, never the original plaintext password."
  - "Password hashing does not protect the login request in transit, so HTTPS is still required."
```

```quiz
type: mcq
question: What should the access-token payload contain?
options:
  - The user's password plus the full database connection URL
  - Only the user id and role needed for one short request
  - Every field stored directly on the user document
  - The Stripe secret key and the client API base URL
correct: 1
explanations:
  - "A payload with a password or a connection string hands account access to anyone who reads it."
  - "The user id and role are all one request handler needs, and a small payload keeps the token short."
  - "Copying the whole user document puts personal data and the refresh hash inside the token."
  - "Provider secrets belong in server configuration, and a token payload is readable by the client."
```

```quiz
type: mcq
question: A request has no valid credentials. Which response best fits that failure?
options:
  - 401 Unauthorized because identity is missing
  - 403 Forbidden because ownership was checked
  - 409 Conflict because the email already exists
  - 201 Created because the token can be added later
correct: 0
explanations:
  - "A missing or invalid credential means the server cannot tell who is calling, which is 401."
  - "403 answers a caller who is identified but not allowed to touch that Piece or Workshop."
  - "409 describes a state conflict such as a Piece already held by another checkout."
  - "201 reports a successful creation and cannot describe a refusal at all."
```
