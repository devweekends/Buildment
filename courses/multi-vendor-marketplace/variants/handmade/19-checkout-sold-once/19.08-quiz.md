```quiz
type: mcq
id: handmade-checkout-q1
question: Lina and Omar press checkout for the same available cushion cover. Which operation decides who owns its hold?
options:
  - A conditional update matching eligible Piece status
  - The first Cart page to show the Piece as available
  - The first browser request to reach the API server
  - A later scan that removes duplicate pending Orders
correct: 0
explanations:
  - "The database evaluates the state predicate during the atomic update; one claim wins."
  - "A page read can be stale before either buyer attempts a hold."
  - "Arrival at the API does not serialize writes across server instances."
  - "Cleanup after both promises is too late to establish one owner."
```

  - Omar's Checkout ID and the newest expiry time

  - "Cart text is neither current Piece state nor hold ownership."

  - "The tray was never claimed, and payment has not happened."
