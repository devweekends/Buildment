  - "Verify the ID is a valid ObjectId and then return the Booking document"
  - "Check that Rami is a Booking participant or has a narrow audited capability"

  - "Verify that the Booking ID contains enough random characters to resist guessing"

explanations:

  - "Object-level participation and action permission decide this particular read."

  - "Unpredictable IDs can leak and do not replace authorization."
