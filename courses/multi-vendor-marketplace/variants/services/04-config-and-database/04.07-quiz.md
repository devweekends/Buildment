```quiz
type: mcq
question: Which file is safe to commit for teammates who need to configure the SkillSlot server?
options:
  - server/.env with working credentials for each teammate
  - server/.env.example with variable names and placeholders
  - A full export of the production secret manager values
  - A log line that prints the full MongoDB connection string
correct: 1
explanations:
  - A committed .env carries a usable database password, so every reader of the repository can reach production data.
  - Names plus placeholders tell a teammate what to supply without shipping anything that works, so the file is safe in git.
  - An export of the secret manager hands over every credential at once and cannot be rotated quietly afterwards.
  - A logged connection string usually embeds the password, so it survives in terminal scrollback and log storage.
```

```quiz
type: mcq
question: Why should the server connect to MongoDB before it starts listening for HTTP requests?
options:
  - It stops routes accepting work the database cannot serve
  - It makes every MongoDB query run inside the browser tab
  - It removes the need for any error handling after startup
  - It automatically seeds the production data on every boot
correct: 0
explanations:
  - A request that arrives before the connection is ready fails inside the handler, so the port must open only after connect resolves.
  - Queries run inside the Node process, and the browser tab never holds a database credential or a driver connection.
  - Query errors, dropped connections and validation failures still need handling after a successful connect.
  - Seeding is a deliberate script run against a chosen database, and a boot sequence must never decide to write sample data.
```

```quiz
type: mcq
question: Which value must stay in server-side configuration rather than a Vite client environment variable?
options:
  - The public app name shown in the browser tab
  - The public API base URL used by the client
  - The MongoDB URI that carries credentials
  - A UI feature label defined in the config
correct: 2
explanations:
  - The app name is display text, so a client variable exposes nothing that a page source does not already reveal.
  - The API base URL has to reach the browser by design, which is why it is the one value a Vite variable is for.
  - The URI contains the database user and password, and a Vite variable is inlined into the bundle for anyone to read.
  - A feature label is presentation copy, and no deployment secret depends on how it is spelled.
```
