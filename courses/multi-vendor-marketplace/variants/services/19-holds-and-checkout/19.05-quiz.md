question: "Two clients read the same free offer before either submits checkout. What establishes exclusive ownership?"
options:
  - "The earlier page load, because its availability response has the oldest timestamp"
  - "A unique provider-and-block claim insert committed with the held purchase"
  - "A browser lock around the Checkout button in each client's open tab"
  - "A final free-slot query run immediately before two independent Booking inserts"
correct: 1
explanations:
  - "A displayed offer is advisory and grants no ownership."
  - "The database unique key permits only one live claimant for each occupied block."
  - "Separate devices and API instances cannot share a browser lock."
  - "Both queries can still see free before either independent insert commits."
