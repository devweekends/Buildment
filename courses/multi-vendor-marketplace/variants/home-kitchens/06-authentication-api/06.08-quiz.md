```quiz
type: mcq
question: Why is bcrypt appropriate for storing Sufra passwords?
options:
  - Its deliberate slowness and salting make guessing costly
  - It encrypts each password so the client can decrypt it
  - It stores the original plaintext password inside the hash
  - It removes the need for HTTPS on the login routes
correct: 0
explanations:
  - Deliberate slowness plus a per-password salt makes offline guessing expensive after a leak.
  - Hashing is one way, so there is no plaintext for the client to recover.
  - The stored hash is derived from the password and never contains it.
  - HTTPS still protects the credential while it travels to the API.
```

```quiz
type: mcq
question: What should the access-token payload contain?
options:
  - The user's password plus the full database connection URL
  - Only the user id and role needed for one short request
  - Every field stored directly on the user document
  - The Stripe secret key and the client API base URL
correct: 1
explanations:
  - A password and a connection URL in one payload hand an attacker both credentials at once.
  - The user id and role are what a single short request needs for identity and permission.
  - Copying the whole document bloats every request and exposes fields the request never uses.
  - Payment and client configuration secrets must never travel inside a token the browser holds.
```

```quiz
type: mcq
question: A request has no valid credentials. Which response best fits that failure?
options:
  - 401 Unauthorized because identity is missing
  - 403 Forbidden because ownership was checked
  - 409 Conflict because the email already exists
  - 201 Created because the token can be added later
correct: 0
explanations:
  - Identity is missing, so the request is unauthenticated and 401 is the honest answer.
  - 403 says the caller is known but not allowed, which needs an identity to check ownership against.
  - 409 describes a state conflict such as a duplicate email at registration, not a missing token.
  - 201 reports a created resource and says nothing about a missing credential.
```
