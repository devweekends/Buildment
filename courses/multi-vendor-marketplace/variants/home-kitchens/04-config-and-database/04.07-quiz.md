```quiz
type: mcq
question: Which file is safe to commit for teammates who need to configure the Sufra server?
options:
  - server/.env with working credentials for each teammate
  - server/.env.example with variable names and placeholders
  - A full export of the production secret manager values
  - A log line that prints the full MongoDB connection string
correct: 1
explanations:
  - A committed .env with working credentials puts live database access in version control for every reader.
  - Names plus placeholders show each Sufra deployment what to supply without carrying a usable secret.
  - An export of production values hands over every credential at once and cannot be rotated quietly.
  - A logged URI usually embeds the password, so it leaks into terminal scrollback and log storage.
```

```quiz
type: mcq
question: Why should the server connect to MongoDB before it starts listening for HTTP requests?
options:
  - It stops routes accepting work the database cannot serve
  - It makes every MongoDB query run inside the browser tab
  - It removes the need for any error handling after startup
  - It automatically seeds the production data on every boot
correct: 0
explanations:
  - A diner's order request should never reach a route whose database is still unreachable.
  - Queries run inside the Node process, not inside the browser tab.
  - Error handling is still required after startup for every query and every dropped connection.
  - Seeding is a deliberate script run that a boot sequence must not perform.
```

```quiz
type: mcq
question: Which value must stay in server-side configuration rather than a Vite client environment variable?
options:
  - The public app name shown in the browser tab
  - The public API base URL used by the client
  - The MongoDB URI that carries credentials
  - A UI feature label defined in the config
correct: 2
explanations:
  - The app name is public text, so a client variable exposes nothing sensitive.
  - The API base URL must reach the browser by design and is public information.
  - The URI carries the database user and password, so it belongs in server configuration only.
  - A feature label is display text that no deployment secret depends on.
```
