```quiz
type: mcq
question: "A design has no queue and no workers. The board shows $2.31 an hour and a slowest 1 in 100 of 116 ms, against $2.45 and 119 ms for the reference design. It fails two checks. What should you conclude?"
options:
  - "The saving is real, so it is the better design"
  - "It skips a job, so the small saving is no win"
  - "The queue slows every search, and this removes it"
  - "The cache makes up for the missing queue"
correct: 1
explanations:
  - "The saving is only $0.14 an hour, and it comes from doing less. The design fails the change check and the worker check, so it does not do its job."
  - "Right. Without a queue and a worker, no product change reaches the index. The numbers hardly move because changes are rare, which makes the missing job easy to miss. Read the functional checks first."
  - "The queue is off the search path. A search never waits for it, so removing it cannot speed searches up by more than the few changes it carries."
  - "The cache serves suggestions and protects the database. It has no part in getting a change to the index."
```

```quiz
type: mcq
question: "About 1 lookup in 40 leaves a product change, and 3,000 lookups a second arrive. The indexing worker stops for 5 minutes and then returns. Each worker handles 2,400 changes a second. How many workers clear the waiting changes (the backlog) within 30 seconds of returning?"
options:
  - "One, with 2,325 a second to spare"
  - "Two, because every part needs a spare"
  - "Three, because the board needs one for every 1,000"
  - "None, because a queue clears itself on restart"
correct: 0
explanations:
  - "Right. 75 new changes a second leave 2,325 a second to spare. The 22,500 waiting changes take about 10 seconds, inside the 30 seconds allowed. The queue holds the changes while the worker is away, so no spare worker is needed."
  - "A second worker clears the backlog in 5 seconds but costs $0.12 an hour, which puts the design over its budget. The queue already protects the changes while the worker is down."
  - "There is no such rule. Capacity is what matters: one worker handles 2,400 a second and only 75 arrive."
  - "A queue only holds changes. Something must take them out, and faster than they arrive, or the waiting changes stay."
```

```quiz
type: mcq
question: "Eight memory-small search nodes and four memory-medium search nodes cost the same and both pass at peak. One node dies in each design. Which design is slower afterwards, and why?"
options:
  - "The four nodes, because a loss takes a quarter of the fleet"
  - "The eight nodes, because more nodes means more to coordinate"
  - "Neither, because the load is the same and the cost is equal"
  - "The eight nodes, because small machines are slower than medium"
correct: 0
explanations:
  - "Right. Losing one of four leaves three nodes at 85% busy and p99 near 221 ms. Losing one of eight leaves seven at 73% and p99 near 143 ms. Waiting grows faster than busyness, so the bigger share lost costs more."
  - "Coordination is real in a real cluster, but the board does not charge for it. In the model, eight nodes lose only an eighth and come out ahead."
  - "The load is the same, and it is shared by fewer machines afterwards. How many remain decides how busy they are."
  - "Size does not change how fast one lookup is in the model. A small node and a medium node answer at the same speed; the medium has twice the capacity."
```

```quiz
type: mcq
question: "A team gets all twelve checks green. Two days after launch, shoppers complain that the best-selling red shoes are on page three of the results. What should the team conclude?"
options:
  - "The board is wrong, and the model must be fixed"
  - "The search index needs more nodes to rank well"
  - "The board checks load and survival, not result quality"
  - "The cache is returning stale suggestions to shoppers"
correct: 2
explanations:
  - "The board did what it says. It has no ranking in it, so a good score says nothing about the order of results."
  - "More nodes would carry more load. They would not change which product is first, which is decided by how the products are scored."
  - "Right. The checks measure whether the index answers, in time, and survives a failure. Ranking quality needs its own tests, such as a set of queries with known good answers."
  - "Suggestions are the words offered while typing. They do not decide the order of search results."
```
