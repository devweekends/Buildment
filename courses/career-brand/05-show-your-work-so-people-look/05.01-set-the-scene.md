## A GitHub link nobody opens

<InteractiveCanvas slug="career-m5-link-nobody-opens" />

Moath is a frontend developer. He sends a founder the link to his recipe app's repository. The README starts with install commands. To see the app, the founder would have to download the code, install it and set it up. The founder moves on. The app may be good. The founder never got far enough to find out. Watch what the founder does when the README opens.

<GoDeeper title="What the founder was asked to do">

Count the steps in Moath's README. First, copy the code to your own computer. Second, install the packages the app needs. Third, set the variables the app reads when it starts. Fourth, start a database. Only then does a screen appear.

None of these steps is hard for a developer. The problem is that all of them come before the reward. A founder reading applications between other tasks will not pay four steps to find out whether one app is worth looking at.

Notice that Moath did nothing wrong in the code. The mistake is in the order. His README begins with what the reader must do. It should begin with what the reader will see.

</GoDeeper>

## A minute to wake, then a sign-up

<InteractiveCanvas slug="career-m5-sleep-then-signup" />

Watch the demo link Moath also sends. It runs on a free plan, which can put an app to sleep. The founder waits about a minute for it to wake. Then it asks for a sign-up and an email confirmation. The founder closes the tab. Both obstacles are normal on a free plan.

<GoDeeper title="Why the demo was asleep">

Some free hosting plans save money by switching an app off when it has had no visitors for a while. The next visitor wakes it, and waits. One host's free web service sleeps after 15 minutes without traffic and takes about a minute to wake (checked 2026-10; check before you rely on it). Other hosts have other rules, and the rules change.

The story gives no number of seconds for the founder's patience, because nobody has a reliable one. The lesson is smaller and safer: a reader who gives you a moment should not spend it on a loading screen and a form.

</GoDeeper>
