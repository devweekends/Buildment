# Organization API: learner progress report

The organization API lets an authorized partner read progress for a learner enrolled through that
organization. The learner must already have an enrollment for the requested course.

## Request

```http
GET /integrations/v1/progress?course_id=<course-id>&learner_email=<learner-email>
x-buildment-access-key: <organization-access-key>
x-buildment-secret-key: <organization-secret>
```

Both credentials are required. The API only returns an enrollment owned by the authenticated
organization; a missing or out-of-scope enrollment returns `404`.

## Response

The response is snake case. `modules` contains the learner's course release, with every chapter in
that release, including chapters the learner has not started. Chapter progress and scores are
summaries; learner answers and submission contents are not exposed.

### Field notes

- `status` is the course progress state: `NOT_STARTED`, `IN_PROGRESS`, or `COMPLETED`. The
  separate `lifecycle` reports access state, such as `PENDING_ACCOUNT` or `PAYMENT_REQUIRED`.
- `modules[].chapters[]` is the source for chapter-level milestones. Each chapter's `status` is
  `NOT_STARTED`, `IN_PROGRESS`, or `COMPLETED`; `completed` is a boolean convenience field.
- Missing progress records are reported as `NOT_STARTED` with zero counts and no timestamps.
- Chapter progress is 100 for a completed chapter. Otherwise, it is the rounded ratio of completed
  blocks to total blocks (or zero when no progress is recorded).
- `progress_percent` on a module is the rounded average of its chapter percentages.
- `completed_lessons` and `total_lessons` are kept as compatibility aliases for
  `completed_chapters` and `total_chapters`.
- `time_spent_seconds` sums tracked chapter study time. Use seconds as the canonical unit.
- `unassigned_chapters` is for active course chapters without a module in courses that do not use
  pinned releases.
- `report_generated_at` records when Edorax assembled this response. The endpoint is pull-based;
  partners refresh it when they need updated progress.
