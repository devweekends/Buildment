## Risks

| # | Risk | Mitigation |
|---|---|---|
| R1 | Drafting, critic A and the canvas work come from one model family | Critic B and the blind key check run on a second, independent model family; a human key check and human review are requested in the PR |
| R2 | Chapters drafted before G2B may need rework | Short roadmap with open decisions; the PR states the order of work |
| R3 | 1,200-word chapters are long for second-language readers on phones | Short paragraphs, one answer quality per chapter, worked weak and strong answers |
| R4 | Popular interview claims (six seconds, 55/38/7, humblebrag weaknesses, Dunning-Kruger as "beginners think they are experts") stated as fact | Writers follow the dossier's "phrase it this way" notes; critic B checks every research claim against the dossier |
| R5 | The AI interviewer flatters, leads or rewards long answers | Rubrics built on finding 11; the course teaches learners to read feedback critically (7.2); mentors read transcripts |
| R6 | Learners paste private data into the AI interviewer | One-line privacy rule before every drill; examples use roles, not names |
| R7 | The course depends on an unmerged platform PR | The PR says so; the course is not opted in to publishing |
