```quiz
type: mcq
question: "A phone joins the café Wi-Fi, where the router 10.5.0.1 is also the DNS server. It then opens http://shop.example.com. In the gateway decision, the phone sees that the web server is outside its network and chooses the gateway. Which order is right, from joining to the first packet of the web connection, the SYN?"
options:
  - "Lease, DNS question, ARP for the router, gateway decision, SYN"
  - "Lease, ARP for the router, DNS question, gateway decision, SYN"
  - "Lease, ARP for the router, gateway decision, DNS question, SYN"
correct: 1
explanations:
  - "The DNS question is sent to 10.5.0.1, which is on the phone's own network. To send it, the phone needs the router's hardware address first, so the ARP comes before the question."
  - "Right. The lease gives the address. The phone needs the router's hardware address before its first packet, the DNS question. The answer gives the web server's address. Only then can the phone decide to use the gateway, and then it sends the SYN."
  - "The gateway decision is about the web server's address, and the phone does not have that address until the DNS question has been answered."
```

```quiz
type: mcq
question: "Three phones fail. Phone 1: ip addr shows no inet line on its interface. Phone 2: ip route get 203.0.113.80 answers 'RTNETLINK answers: Network is unreachable'. Phone 3: a ping to 203.0.113.45 gets 2 received, but dig ends with 'communications error to 192.168.1.1#53: timed out'. Which row names the broken layer for each phone?"
options:
  - "1: gateway, 2: route out, 3: DNS"
  - "1: address, 2: gateway, 3: route out"
  - "1: address, 2: route out, 3: DNS"
correct: 2
explanations:
  - "Phone 1 never got an address, so it fails at check 2. The gateway is check 3, and the phone has not even got that far."
  - "Phone 2 fails at the route check, not at the gateway. And phone 3 can ping, so packets leave and return. Its route out works."
  - "Right. No inet line is the address. 'Network is unreachable' from ip route get is the phone's own missing route. A ping that works with a dig that times out is DNS."
```

```quiz
type: mcq
question: "A laptop and a phone sit behind one home router. Both open a connection to the same server and both send from source port 41000. The laptop's connection started first. What does the server see?"
options:
  - "The router's address, but a new port for the second"
  - "The router's address for both, and port 41000 for both"
  - "The laptop's and the phone's own private addresses"
correct: 0
explanations:
  - "Right. The address is rewritten for both. The port is kept unless it would clash, and the second flow clashes with the first, so the router gives it a new port. The lab showed 41000 for the laptop and another port for the phone."
  - "Two flows from the same router address cannot share one port to the same server, because the server could not tell them apart. The second flow gets a new port."
  - "The server never sees the private addresses. The router rewrites the source address to its own outside address."
```

```quiz
type: mcq
question: "From a server outside, you use curl on the router's outside address, 203.0.113.1, port 22. Nothing on the router listens on port 22, and no rule forwards it. What happens?"
options:
  - "It times out after a few seconds"
  - "It is refused at once"
  - "It reaches the laptop's own port 22"
correct: 1
explanations:
  - "A timeout means silence. Here the router answers and says that nobody listens, so the refusal comes straight away."
  - "Right. An unforwarded port that nothing listens on is refused at once, with a connection error. A missing return route is the case that gives silence."
  - "Only a port that a rule forwards reaches a device behind the router. This port has no such rule, so the router handles it and nothing is behind it."
```
