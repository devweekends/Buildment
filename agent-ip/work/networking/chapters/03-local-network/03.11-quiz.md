```quiz
type: mcq
question: "A laptop on a campus network has the address 10.45.201.130 and the prefix /19. What is the network address?"
options:
  - "10.45.201.0"
  - "10.45.200.0"
  - "10.45.192.0"
correct: 2
explanations:
  - "That keeps the first three numbers, a shortcut that works only for /24. A /19 cuts inside the third number, so the 201 must change."
  - "That would be right for /21, where the third number is a multiple of 8. A /19 keeps three bits of the third number, so it must be a multiple of 32."
  - "Right. A /19 mask is 255.255.224.0. In the third number, 201 is 11001001 and 224 is 11100000. The AND is 11000000, which is 192."
```

```quiz
type: mcq
question: "A laptop has just started and its ARP table is empty. It sends a packet to a printer at 192.168.4.30 on the same network. Which devices receive the laptop's first frame?"
options:
  - "Every device on that network"
  - "Only the printer itself"
  - "Only the router of the network"
correct: 0
explanations:
  - "Right. The laptop does not know the printer's MAC address yet, so it broadcasts an ARP request to ff:ff:ff:ff:ff:ff, and every device hears it. [S22]"
  - "The laptop cannot send to the printer's MAC address, because it does not have it. Only the answer to the broadcast is sent to one device."
  - "The printer is on the same network, so the router is not involved. A router is needed only when the destination is not local."
```

```quiz
type: mcq
question: "A laptop uses four ranges: home 192.168.1.0/24, Docker 172.20.0.0/16, office 172.20.8.0/21 and VPN 172.21.0.0/16. Which pair overlaps?"
options:
  - "Docker and the VPN, side by side"
  - "Docker and the office, nested"
  - "Home and Docker, both private"
correct: 1
explanations:
  - "Docker ends at 172.20.255.255 and the VPN starts at 172.21.0.0. They touch, but they share no address, so they do not overlap."
  - "Right. The office covers 172.20.8.0 to 172.20.15.255, and that lies inside Docker's 172.20.0.0 to 172.20.255.255."
  - "Both are private, but private is a kind, not a place. The two ranges start with different numbers and share no address."
```

```quiz
type: mcq
question: "A script stores the address 10.1.2.9 as one number. Which number is right?"
options:
  - "151126282"
  - "167840002"
  - "167838217"
correct: 2
explanations:
  - "That reads the parts in reverse order, with 9 as the biggest part. The first part, 10, is worth 16,777,216 times its value."
  - "That swaps the last two weights, so 2 counts as 1 and 9 counts as 256. The third part is worth 256 and the fourth is worth 1."
  - "Right. 10 x 16,777,216 + 1 x 65,536 + 2 x 256 + 9 = 167,772,160 + 65,536 + 512 + 9 = 167,838,217."
```

  - "Shared, because it is near the private range"

explanations:
  - "Right. The private block 172.16.0.0/12 ends at 172.31.255.255, so 172.32.0.5 is outside it and matches no list. [S8]"
  - "Only part of the 172 range is private. The block 172.16.0.0/12 stops at 172.31.255.255. [S8]"
