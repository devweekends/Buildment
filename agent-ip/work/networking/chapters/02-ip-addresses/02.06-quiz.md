```quiz
type: mcq
question: "A router's settings page shows the address 192.168.0.1. A script stores it as one number. Which number is right?"
options:
  - "3232235520"
  - "3232235521"
  - "3232235776"
correct: 1
explanations:
  - "That is the number for 192.168.0.0. The last part, 1, was left out. Add 1 x 1 for the last part."
  - "Right. 192 x 16,777,216 + 168 x 65,536 + 0 x 256 + 1 = 3,221,225,472 + 11,010,048 + 0 + 1 = 3,232,235,521."
  - "That counts the last part as 1 x 256. The last part is worth 1. The weight 256 belongs to the third part, which is 0 here."
```

```quiz
type: mcq
question: "A cloud console asks for a block of exactly 512 addresses, written as a prefix. Which prefix gives 512?"
options:
  - "/23"
  - "/9"
  - "/22"
correct: 0
explanations:
  - "Right. 512 is 2 to the power 9, so the block has 9 host bits. The prefix counts the fixed bits: 32 - 9 = 23."
  - "That writes the 9 host bits as the prefix. A /9 has 23 host bits, which is 8,388,608 addresses."
  - "A /22 has 10 host bits, which is 1,024 addresses: twice as many as the console asked for."
```

```quiz
type: mcq
question: "Which one of these addresses is public?"
options:
  - "100.90.12.1"
  - "172.20.14.9"
  - "192.169.0.7"
correct: 2
explanations:
  - "The block 100.64.0.0 to 100.127.255.255 is shared space. The second number 90 is inside it, so this address is shared, not public."
  - "The second number 20 is between 16 and 31, inside 172.16.0.0 to 172.31.255.255. This address is private."
  - "Right. In the 192 range only 192.168 is private, so 192.169.0.7 matches none of the lists and is public."
```

```quiz
type: mcq
question: "A Linux laptop sends a packet to a server. The capture on the server shows ttl 61. How many routers did the packet cross?"
options:
  - "4 routers"
  - "3 routers"
  - "61 routers"
correct: 1
explanations:
  - "That counts links: three routers make four links. The TTL goes down by one for each router, not for each link."
  - "Right. A Linux computer starts a packet at TTL 64, and each router lowers it by one. 64 - 61 = 3."
  - "61 is what is left of the TTL, not a count of routers. The packet started higher and lost one at each router."
```
