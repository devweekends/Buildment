```quiz
type: mcq
question: "A monitoring tool prints the address 2001:0db8:0000:0000:0000:ff00:0042:8329. Which one is the standard short form?"
options:
  - "2001:db8::ff:42:8329"
  - "2001:db8::ff00:42:8329"
  - "2001:db8:0:0:0:ff00:42:8329"
correct: 1
explanations:
  - "This cut the zeros at the end of ff00 and left ff. Only leading zeros go, never the ones at the end of a group, so that would be a different address."
  - "Right. Drop the leading zeros, replace the longest run (three zero groups) with ::, and keep the letters in lower case."
  - "This is valid, and every reader gets the right address. But the standard form replaces the run of three zero groups with ::, so this one is not it."
```

```quiz
type: mcq
question: "A laptop at 192.168.1.23 sits behind a home router whose outside address is 198.51.100.2. It loads a page from a server at 203.0.113.80. Which source address does the server see?"
options:
  - "192.168.1.23, the laptop itself"
  - "192.168.1.1, the router's inside"
  - "198.51.100.2, the router's outside"
correct: 2
explanations:
  - "This address works only inside the home. The server cannot reach it, so the router rewrites it before the packet leaves."
  - "This is the router's address on the home side. The packet leaves through the outside, so the server sees the outside address."
  - "Right. The router with NAT rewrites the source to its own outside address, and the server sees that address."
```

```quiz
type: mcq
question: "A phone and a laptop behind one NAT router both use source port 40000 at the same moment, to port 80 on the same server. What can the server see?"
options:
  - "One address, and one of the ports changed"
  - "Two addresses, one for each device"
  - "One address, and both ports stay 40000"
correct: 0
explanations:
  - "Right. Both devices share the router's one outside address. The router keeps a port unless two flows would clash, and then it rewrites one of them."
  - "The server sees only the router's outside address. Two addresses, one for each device, is what you get with IPv6 and no NAT."
  - "Two flows from the same address and the same port to the same place would clash. The router has to change one of the ports."
```

```quiz
type: mcq
question: "A tablet has the global address 2001:db8:77:1::9 on a network with no NAT. It loads a page from a server at 2001:db8:ffff::80. Which source address does the server see?"
options:
  - "The router's address, as with NAT"
  - "The tablet's own, 2001:db8:77:1::9"
  - "Only the prefix, 2001:db8:77:1::"
correct: 1
explanations:
  - "That is what the server sees with IPv4 and NAT. Without NAT, no router rewrites the source address."
  - "Right. No router rewrites the address, so the server sees the tablet's own global address and can tell it from every other device."
  - "The prefix names the network only. The packet carries the whole address, including the last 64 bits that name the tablet."
```

```quiz
type: mcq
question: "The server at 2001:db8:ffff::80 sends the tablet a packet that the tablet never asked for. The home router has a stateful filter. What happens to the packet?"
options:
  - "It arrives, because the address is global"
  - "The router rewrites the address and delivers it"
  - "The filter drops it, because nobody asked"
correct: 2
explanations:
  - "A global address only says where a packet goes. The filter decides what may come in, and it has no note for this packet."
  - "Rewriting addresses is the job of NAT, and there is no NAT here. The filter only lets a packet in or drops it."
  - "Right. The filter lets in replies to connections that a device inside started. This packet has no such connection, so it is dropped."
```
