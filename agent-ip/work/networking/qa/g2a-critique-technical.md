# G2A critique, technical lens: networking roadmap

## Verdict

The sequence and the core arithmetic (CIDR, ARP, MAC change per hop, longest prefix match, DHCP four-step, TTL and Time Exceeded, UDP and TCP, NAT/NAPT, CGNAT range, RFC 1918 and documentation ranges) are right at outcome level, and the build environment test in dossier 5.5 genuinely covers the masquerade, DHCP, DNS and IPv6-veth paths. The roadmap is not safe to send to instructors yet. Three things carry most of the risk. First, the headline NAT demonstration ("source address and port rewritten") is unsupported: Linux masquerade normally keeps the source port, and the dossier never records the pre-NAT port. Second, the interactive plan leans on "existing renderers, data only" that cannot do what the chapters ask (the sequence renderer has two to four lanes and no inputs; the timeline renderer is a millisecond lane trace driven by a per-canvas model), and the "fall back to `[sequence]`" promise does not work for graded labs. Third, the capstone and several Build chapters depend on things the environment test did not cover (guest isolation rules, DNAT, per-namespace resolver files, a "what is my IP" service with no interpreter in the image, fault injection against a single dnsmasq) and are time-boxed well below what a beginner needs. There are no S1 defects, but nine S2 defects block approval until fixed.

## What works (preserve)

- The environment section is honest: it separates what was tested (Windows, `--privileged`) from what was not (macOS, native Linux, WSL 2 without Docker), and it correctly moves real-path commands (`tracert`, `curl ifconfig.me`) to the host after the test showed the Docker Desktop path is hidden.
- Documentation ranges for lab "public" addresses are confirmed to work as interface addresses (dossier 5.5), and the capstone plan (two-sided capture at the router) is the right evidence for NAT.
- The `[addr]` renderer reuses the same address library as the code exercises, so canvas and reference solution cannot disagree. Modes listed match every chapter that references them.
- Hostile cases are named where it counts: 3.5 overlap with Docker's `172.17.0.0/16`, the `/30` guest probe, "missing return route" in the lab.
- Chapter minute totals add up (checked: 2,420 minutes, 71 chapters, 29 Learn, 9 Build, 3 labs).
