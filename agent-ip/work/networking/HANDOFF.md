## What a fresh session must know

- **Lab environment:** `docker run --privileged ubuntu:24.04` plus the tools listed in the roadmap's "Build environment". Tested on Docker Desktop for Windows. Use `MSYS_NO_PATHCONV=1` before `docker run -v` in Git Bash. `apt-get` inside the container can take several minutes on this connection.
- **Facts the tests established**, which the course depends on:
  - Linux masquerade keeps the source port unless it clashes.
  - `conntrack -L` shows the real NAT table.
  - A masquerade-only router is not a firewall.
  - An unforwarded port gives "connection refused".
  - The Linux DHCP client gives up with no address; there is no `169.254.x.x` fallback.
  - `traceroute` and `dig +trace` inside the container cannot see the real internet path, so real-path commands run on the host.
  - A mask mismatch gives "Network is unreachable" one way and silent loss the other.
- **Boundaries:** the system design course keeps TLS, HTTP versions and real-time; the Linux course owns namespaces and cgroups. Do not edit other `buildment-*` worktrees.
